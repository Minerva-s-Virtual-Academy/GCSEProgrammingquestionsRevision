📌 Variables vs Constants

Variables: Can change while program runs.

count = 0
score = score + 10

Constants: Fixed values, written in ALL_CAPS by convention.

SIDES = 6
THROWS = 3

🔀 Selection & Logic

if / elif / else controls execution flow.

Logical Operators:

  • or: True if at least one condition is True.
  • and: True only if ALL conditions are True.
  • ==: Checks equality.

if roll == 3 or roll == 6:
    booster += 1

🔁 Loop Constructs

for i in range(n) repeats code n times.

for i in range(THROWS):
    roll = random.randint(1, SIDES)

Indentation Note: Python requires 4 spaces for block body execution!

📝 Exam Question Walkthrough: Question 04c Dice Game

In your Python practical exam, you are often given incomplete code skeletons or Parsons blocks to arrange. Let's look at the problem requirements for Question 04c:

📋 Game Rules & Requirements:

  • The dice is rolled 3 times (using constant THROWS = 3).
  • Each roll is a random number between 1 and 6 (using SIDES = 6).
  • Roll values are accumulated into subtotal.
  • booster starts at 1. Each time a 3 or 6 is rolled, booster increases by 1.
  • finalScore equals subtotal * booster.

# Q04c - Model Python Solution

import random

# Program constants
SIDES = 6
THROWS = 3

# Initialise variables
roll = 0
subtotal = 0
booster = 1
finalScore = 0

# Roll dice 3 times
for i in range(THROWS):
    # Display number rolled
    roll = random.randint(1, SIDES)
    print("Rolled:", roll)
    
    # Update subtotal
    subtotal = subtotal + roll
    
    # Check for roll of 3 or 6 and increment booster if needed
    if roll == 3 or roll == 6:
        booster = booster + 1

# Calculate and output final score
finalScore = subtotal * booster
print("Score", finalScore)
